Architecture Context & Flow Overview

The system is a Modular Monolith in Node.js/Express with schema isolation (PostgreSQL schemas: auth, candidate, ledger). Modules communicate strictly via internal interfaces and an in-process eventBus:

Trade Tester/Supt → [Auth Module: RS256/MFA] → [Candidate Module: Intake/Media/Approval] → (eventBus: assessment.approved)
                    → [Ledger Module: W3C VC → SHA-256 → Polygon Relayer] → Polygon Amoy Smart Contract
External Employers → [Public Verification Module: Hash Reconciliation < 2.0s] → [Valid / Tampered / Revoked]

Collaboration Rules & Zero-Collision Protocol

  • Strict File Boundaries: Neither track touches files outside their assigned directories. No joint file editing.
  • Interface Contracts First: The interface between Track A and Track B is purely the event payload emitted by eventBus.emit('assessment.approved', payload). That JSON contract is frozen on Day 1.
  • Daily Standup (9:30 AM): 15-minute sync focusing exclusively on blockers and interface adherence.

Backend Definition of Done (DoD) Criteria

  • Zero Runtime Exceptions: No unhandled promise rejections or TypeError crashes across all endpoints.
  • Zero PII On-Chain: Personal data strictly off-chain; CNIC salted and hashed before persistence ([NFR-SEC-03]).
  • End-to-End Lifecycle Verified: Enrolment → Scoring → Approval → Relayer Mint → Public Verification fully functional.
  • SLA Verification Compliance: Public lookup via /api/verify/:credentialId returns within < 2.0 seconds ([NFR-PER-01]).
  • Security Baselines: RS256 JWT, rate limits on all endpoints (60 req/min), CORS restricted, Helmet security headers enabled.
